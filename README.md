# Port Forge (web)

**→ [arjunkdaf.github.io/portforge-web](https://arjunkdaf.github.io/portforge-web)**

A browser tool that turns a PC game folder into a **PortMaster-ready port** for a
handheld.

Everything runs locally in your browser — nothing is uploaded. Drop a game folder
in; the site figures out the engine, flags anything it needs or can't handle, and
hands back a single zip. Extract that onto your device's SD card and install it
with Port Forge.

The site walks you through each step and only ever offers what's actually
supported, so it's the source of truth for what works — not this page.
